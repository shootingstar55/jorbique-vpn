# Архитектура

Продукт: личный VPN-клиент для macOS и Windows. Это не одна программа с двумя
сборками, а два разных приложения: они решают одну задачу (пустить
трафик пользователя через VPN), но устроены и написаны по-разному, под
особенности каждой системы. Общего кода между ними почти нет, кроме
пары служебных модулей (проверка обновлений VPN-движка и защищённое
соединение с сервером).

| | macOS | Windows |
|---|---|---|
| Из чего состоит | иконка в меню-баре + фоновый сервис | одно приложение |
| Права доступа | сервис работает от администратора, иконка от обычного пользователя | всё приложение работает от администратора |
| Интерфейс | нативный macOS-интерфейс | окно с веб-интерфейсом внутри (HTML/JS) |
| VPN-протоколы | sing-box: прокси-outbounds из профиля сервера | sing-box: прокси-outbounds из профиля сервера |
| Установка | пакет `.pkg` | обычный `.zip` с программой |

# macOS

## Из чего состоит

Приложение состоит из двух частей.

Первая: иконка в строке меню, которую видит пользователь. Она работает
от имени обычного пользователя и никогда не запрашивает права
администратора при обычном использовании.

Вторая: фоновый сервис, который работает от администратора (root).
Всё, для чего нужны права администратора: включение VPN-туннеля,
изменение сетевых настроек и DNS, установка и обновление самого
приложения: делает именно он.

```text
   пользователь                       администратор

   иконка в меню-баре   <--->   фоновый сервис
   (видимый интерфейс)          (работает в фоне)
```

Иконка и сервис общаются между собой напрямую, без участия пользователя.
Поэтому после установки права администратора спрашиваются один раз, а
не при каждом включении VPN.

## Установка и запуск

Приложение ставится через обычный установщик `.pkg`. При первой
установке один раз запрашивается пароль администратора: это нужно,
чтобы поставить фоновый сервис. Дальше сервис запускается сам при
включении компьютера, а иконка в меню-баре при входе пользователя в
систему.

## Где что лежит

- сама программа: `/Applications/Jorbique VPN.app`
- бинарники демона, конфигурация и скачанные профили:
  `/Library/Application Support/JorbiqueVPN`
- логи демона и sing-box: `/Library/Logs/JorbiqueVPN`
- логи иконки меню-бара (у каждого пользователя свои):
  `~/Library/Logs/JorbiqueVPN`

## Сеть и VPN

Когда пользователь включает VPN, фоновый сервис настраивает сеть на
уровне системы: поднимает туннель, прописывает DNS-серверы, добавляет
нужные маршруты. Используется один движок: sing-box.

Профиль подключения (`singbox_client.json`) приложение скачивает с
`jorbique.one`. В туннель идут только прокси-outbounds профиля (VLESS,
AnyTLS, Snell и т. п.), то есть каждое подключение меняет
внешний IP. `endpoints` (WireGuard, OpenVPN, Tailscale) из профиля
выбрасываются вместе с DNS-серверами и правилами маршрутизации, которые
на них ссылались. UUID пользователя в профиле нет: приложение
подставляет введённый при первом запуске UUID в пустые поля `uuid` /
`password`.

## Интерфейс

Меню-бар использует нативные элементы macOS, а главное окно и панели
настроек — общий Vue-интерфейс внутри WKWebView. Из меню можно включить
или отключить sing-box и открыть главное окно.

## Сборка и распространение

Собирается один универсальный файл, который работает и на Intel-, и на
Apple Silicon-маках. Пакет подписан ad-hoc, без нотаризации Apple:
macOS Gatekeeper предупредит о неизвестном разработчике, если скачать
пакет из интернета.

## Обновление и откат

На каждой машине вместе с приложением ставится небольшой
административный скрипт (`jorbique-vpn-admin`). Через него можно
поставить новую версию поверх старой, посмотреть, какая версия сейчас
стоит, и откатиться обратно на предыдущую, если новая версия оказалась
неудачной. Перед обновлением скрипт сам сохраняет копию текущей
установки, поэтому откат не требует переустановки с нуля. Подробности:
[upgrade-rollback.md](upgrade-rollback.md).

# Windows

## Из чего состоит

На Windows это одно приложение без разделения на части. Оно целиком
работает с правами администратора: при запуске Windows один раз
показывает системный запрос на подтверждение (UAC).

```text
   запуск приложения
          |
   запрос прав администратора (UAC)
          |
   приложение запускает VPN-движок sing-box
   как отдельный процесс и следит за ним
```

## Интерфейс

Интерфейс: окно с веб-страницей внутри (простой HTML и JavaScript, без
тяжёлого фреймворка). Это тот же подход, что у многих современных
десктоп-приложений: интерфейс верстается как сайт, а показывается в
системном окне.

## Сеть и VPN

Весь системный DNS заворачивается в туннель одним правилом NRPT
(catch-all на DNS-адрес TUN), дальше имена разрешает sing-box по своим
DNS-правилам. При отключении, неудачном подключении и старте после
сбоя правило снимается, чтобы машина не осталась без DNS.

## Где что лежит

Программа не ставится в системную папку через установщик, а
запускается прямо из того места, куда распаковали `.zip`, будь то
Загрузки, рабочий стол или отдельная папка. Все свои данные, настройки
и логи приложение хранит отдельно от самого exe-файла, в папке
пользователя: `C:\Users\<имя пользователя>\AppData\Roaming\JorbiqueVPN`.

## Сборка и распространение

Приложение распространяется как обычный `.zip`-архив с исполняемым
файлом, без установщика и без цифровой подписи. VPN-движок sing-box не
входит в архив: он скачивается самим приложением при первом запуске.
