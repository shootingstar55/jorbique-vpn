# Личный кабинет и лимит устройств

Кнопка «Личный кабинет» есть в главном окне на Windows, macOS и Android. Окно
показывает, чей это UUID, до какого числа действует подписка и какие
устройства привязаны к UUID. Отсюда же устройство можно отвязать или привязать
снова.

Данные приходят с сервера: сервис `jorbique-account` за nginx на
`https://<сервер>/account/v1/` (репозиторий ansible-singbox-server). Лимит
задаёт строка `devices: N` у пользователя в `group_vars/vpn/users.yml`. Если
строки нет, лимита тоже нет.

## Что считается устройством

Устройство определяется по имени и платформе, так же, как в метриках: на
Windows это имя компьютера, на macOS имя из «Системных настроек», на Android
имя телефона из настроек. ID устройства считается из этих двух значений
(`internal/account.ThisDevice`). Два компьютера с одинаковым именем на одной
ОС будут одним устройством. После переименования устройство займёт новое
место, а старое нужно отвязать в кабинете.

## Когда клиент проверяет лимит

Перед каждым подключением клиент сообщает серверу о себе (`account.Gate`):

- новое устройство привязывается само, если есть свободное место;
- если места нет, подключение не начинается, и клиент объясняет, что нужно
  отвязать устройство в кабинете;
- отвязанное устройство само не возвращается: его нужно привязать кнопкой
  «Привязать это устройство»;
- если сервер недоступен или на нём нет сервиса кабинета, клиент подключается
  как обычно. Проверка никогда не оставляет пользователя без VPN из-за сбоя.

На macOS проверку делает приложение в меню-баре перед командой подключения.
Автоподключение фоновой службы её не проходит.

Лимит мягкий: VPN-протоколы проверяют только UUID, поэтому соблюдает его только
этот клиент. Тот же UUID в другом приложении или в подписке /sub не
ограничен.
